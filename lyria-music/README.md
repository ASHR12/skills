Lyria Music Skill
============

Skill for AI Edge Gallery to generate 30-second music clips using
Google Lyria 3 Clip via the Gemini API.

Supports text prompts, image-inspired generation (LLM analyzes the
image and builds a prompt), and combined image + text input.

A Gemini API key is required. Get one at https://aistudio.google.com/apikey

To load skills , please use this link : https://ashr12.github.io/skills/lyria-music/
